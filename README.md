

Semáforos Inteligentes

Sistema de dos semáforos coordinados desarrollado con ESP32, como proyecto de Sistemas Embebidos y Electrónica Digital (2025).

Descripción:
Sistema que coordina dos semáforos mediante contadores digitales, flip-flops y un temporizador 555, con control de un servomotor vía PWM. Incluye comunicación Wi-Fi y sincronización con Blynk IoT para visualización remota del estado del sistema y control de sus funciones.

Componentes y tecnologías:

ESP32
Contadores digitales, flip-flops, temporizador 555
Servomotor (control PWM)
Comunicación Wi-Fi
Blynk IoT (visualización y control remoto)

Lo que aprendí / resolví:
Diagnóstico y corrección de fallas de hardware y software durante las pruebas del sistema, trabajando en equipo para validar el funcionamiento coordinado de ambos semáforos.
